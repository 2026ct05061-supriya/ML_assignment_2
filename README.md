# ML_assignment_2

a. Problem statement: Predicting the rainfall in Australia based on the available past
data. The models implemented will predict whether tomorrow the rainfall will occur
(yes) or not (no). The models will be trained on the past data and verified against the
test data.

b. Dataset description: The dataset contains weather related info such as minimum
and maximum temperature , the amount of rainfall that has occured, and other
parameters required for predicting the rainfall such as wind , humidity , pressure
metrics.
